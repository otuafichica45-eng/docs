描述用户如何开始使用您的产品。他们首先需要做什么？是否有任何先决条件？

一个快速开始应能让用户从零上手使用您的产品。他们将快速获得成功体验，并了解可以完成什么。

## 先决条件

在开始之前，您必须具备：

- 要求一（例如 Node.js 18+、免费账户、API 密钥）
- 要求二（例如兼容的设备、兼容的浏览器、兼容的操作系统）

## 开始使用

<Steps>
  <Step title="安装">
    描述如何安装您的产品或注册。

    ```bash
    npm install your-package
    ```
  </Step>
  <Step title="配置">
    描述首次使用前所需的任何设置或配置。

    ```bash
    your-cli init
    ```
  </Step>
  <Step title="运行">
    展示用户为了看到产品运行所要做的第一件事。

    ```bash
    your-cli start
    ```
  </Step>
</Steps>
